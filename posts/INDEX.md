# posts/ — ศูนย์กลางคอนเทนต์โซเชียล (โพสต์ย้อนหลัง 4-5 เดือน + ต่อเนื่อง)

เดิมทั้งหมดอยู่ใน POST.md ไฟล์เดียวยาวเกิน ย้ายมาแยกเป็นไฟล์ต่อ series แทน (2026-07-28)

## วิธีทำงานต่อจากนี้

- **ฝากหัวข้อไว้ก่อน ไม่ต้องดราฟต์ทันที** → เขียนลง `inbox.md`
- **อยากได้ draft แรกทันที** → บอกในแชท พร้อมหัวข้อ/มุม (เหมือนที่ทำ series D) แล้วผมจะสร้าง/ต่อไฟล์ series ให้ตรงนี้เลย
- ทุกไฟล์ series เป็น **plain text ล้วน คัดลอกลง Facebook ได้ตรงๆ** ไม่มี markdown syntax ปน (ไฟล์นี้กับ inbox.md เป็นข้อยกเว้น เพราะเป็นเอกสารทำงานภายใน ไม่ได้เอาไปโพสต์)
- แต่ละตอนมี 📸 ภาพประกอบแนะนำ + ✏️ แคปชันสั้น/quote ในตัว
- ช่วงที่เป็น `[ใส่ตรงนี้ — ...]` คือจุดที่เว้นไว้ให้ใส่มุมมอง/รายละเอียดส่วนตัวเอง

## จะกลับมาทำต่อยังไง (ไม่ต้อง "ปักหมุด" session)

Claude Code ไม่ได้จำ session เก่าข้ามวันอัตโนมัติ — ของจริงคือไฟล์พวกนี้ ไม่ใช่ history ของแชท
เปิด session ใหม่เมื่อไหร่ก็พิมพ์แค่ "ทำ posts series ต่อ" แล้วบอกหัวข้อ/ไฟล์ที่เกี่ยวข้อง (หรือให้ผมเปิด INDEX.md นี้ก่อนก็ได้) — ผมจะอ่านจากไฟล์เหล่านี้เป็นความจริงตั้งต้นเสมอ ไม่ใช่พึ่งความจำจากแชทเก่า
