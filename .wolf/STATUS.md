## ➜ ที่ user กำลังจะกดทดสอบ (local)

`http://localhost:3000/kanban/import/forum` — แนะนำเริ่มจากห้อง **สมาชิกพรรค (37 ใบ)**
1. แก้ชื่อ/รายละเอียด/วันจัดงาน/สายงาน/พื้นที่/ผู้รับผิดชอบ (หลายคนได้) แล้วรีเฟรชดูว่าค่าอยู่ครบ
2. กด "ไม่เอา" แล้วดูว่าหลุดจากแท็บรอคัด และเอากลับมาได้
3. ติ๊กหลายใบ → กดชิปในแถบบนเพื่อใส่ค่าให้ทั้งชุด → **นำเข้า n ใบ**
4. ใบที่ธงว่าซ้ำต้องถูกกันไว้ จนกว่าจะกด "รู้แล้วว่าซ้ำ นำเข้าเลย"
5. เปิด `/kanban` เช็คการ์ดที่ได้: วันเสร็จ = วันจัดงาน · รูปมาครบ · สายงาน/พื้นที่ติดมา

## ⚠️ ค้าง / รู้ไว้
- **ยังไม่ push** — 4 commit อยู่บนเครื่อง dev เท่านั้น · migration ใหม่ 4 ตัว
